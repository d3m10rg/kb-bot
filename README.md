# Telegram-бот для модерации группы

Бот проверяет новых участников математической капчей, удаляет стикеры из
запрещённых наборов и выдаёт мут после третьего употребления слова «балл» в
любой падежной форме.

Дополнительно бот:

- удаляет игровые эмодзи 🎰 🎲 🎯 🎳 🏀 ⚽ через 60 секунд после отправки;
- выдаёт мут на 5 минут за максимальный результат: 777 у 🎰 (64), 6 у
  🎲/🎯/🎳, 5 у 🏀/⚽; после подтверждения мута поздравляет игрока;
- позволяет администраторам выдавать `/warn @username [причина]` или `/warn [причина]`
  ответом на сообщение участника; начиная с третьего предупреждения выдаёт мут на сутки;
- по `/stats` показывает участников с 1–2 предупреждениями и действующие муты
  с датой и временем окончания по Москве;
- удаляет свои сообщения через 60 секунд, включая предупреждения и капчу.

Речь об игровых сообщениях Telegram с полем `dice`, а не об обычном тексте
с эмодзи или стикерах из произвольных наборов. Значения игр описаны в
[документации Telegram](https://core.telegram.org/api/dice).

## Предупреждения и статистика

Команду `/warn` могут использовать только администраторы. Например:

```text
/warn @username за мат в чате
```

Ответ на первое предупреждение:

```text
Пользователю @username дано предупреждение.
Причина: за мат в чате
Осталось предупреждений до бана: 2
```

Причина необязательна; без неё соответствующая строка опускается. Бот сохраняет
причину последнего предупреждения. Длинная причина отправляется несколькими
сообщениями. После третьего предупреждения остаток равен нулю; после успешного
мута бот добавляет:

```text
@username, ты видимо с 3 раза не понял, посиди в бане на сутки
```

«Бан» в этих сообщениях означает **мут**: участник остаётся в чате, но сутки
не может отправлять сообщения, стикеры и другие медиа.

Администратор может досрочно снять мут командой `/unban @username` или `/unban`
ответом на сообщение участника. Бот подтверждает снятие ограничений через Telegram
и убирает мут из `/stats`. Счётчики предупреждений сохраняются. Команда снимает
также мут за выигрыш или слово «балл». Во время незавершённой капчи сначала
нужно пройти проверку, затем повторить команду. Ответ бота удаляется через минуту.

Счётчик `/warn` сохраняется отдельно для каждого участника каждого чата и
не сбрасывается после мута. Последующие `/warn` при N ≥ 3 снова дают сутки
мута. Предупреждения за слово «балл» по-прежнему имеют отдельный счётчик и
длительность `MUTE_MINUTES`. Более долгий действующий мут не сокращается.

Для поиска по `@username` бот запоминает участников по новым сообщениям и
изменениям членства. Если бот ещё не видел участника или тот сменил username,
используйте `/warn` ответом на его сообщение. Пользователя без username также
можно предупредить ответом. Перед предупреждением бот проверяет текущий
профиль и членство. Администраторов, владельца и ботов он не мутит.

`/stats` доступна только администраторам группы. В первом разделе — пользователи с 1 или 2
предупреждениями `/warn`; во втором — пользователи с действующим мутом и время
его окончания в формате `дд.мм.гггг чч:мм:сс МСК`. Бессрочные муты помечены
отдельно. В статистику входят муты за предупреждения, игры и слово «балл»,
а также ручные муты, об изменении которых Telegram сообщил боту. Временная
блокировка на время капчи в этот список не включается.

Бот сверяет ограничения известных ему пользователей с Telegram: истёкшие и
досрочно снятые муты не показываются. Муты после третьего предупреждения из
старой версии также проверяются при `/stats`. Bot API не предоставляет список
всех участников или всех прежних мутов: о давнем ручном муте неизвестного ему
участника бот узнает из нового обновления Telegram. Если Telegram временно
недоступен, бот явно помечает статистику как содержащую сохранённые данные.

## Выигрыши

После успешного мута бот пишет:

```text
Поздравляю с успешным депом, вот тебе мут на 5 минут
```

Пересланные игры только удаляются. Для мута нужна супергруппа, а боту нужны
права администратора с разрешением ограничивать участников. Если выдать мут
не удалось, бот сообщает причину в чате и пишет подробности в лог. Поздравление
с обещанием мута отправляется только после проверки прав игрока через Telegram.
Уже действующий более долгий мут не сокращается; запрет только на текст
не считается полным мутом. Решение капчи не снимает выданный модерацией мут.

## Запуск

1. Скопируйте конфигурацию и заполните её:

   ```bash
   cp .env.example .env
   ```

2. Соберите и запустите контейнер:

   ```bash
   docker compose up --build -d
   ```

3. Добавьте бота в **супергруппу** как администратора. Ему нужны права:
   удалять сообщения, блокировать пользователей и ограничивать участников.
   В BotFather отключите Privacy Mode, чтобы бот получал обычные сообщения
   группы и мог применять политику слова «баллы».

Логи:

```bash
docker compose logs -f bot
```

Остановка:

```bash
docker compose down
```

SQLite хранится в Docker volume `bot-data`, поэтому попытки, предупреждения,
причины, сроки мутов, известные username, незавершённые капчи и очередь удаления
переживают перезапуск. Новые таблицы и поля создаются автоматически в существующей базе. Просроченные
удаления выполняются после запуска; при работе очередь проверяется раз в секунду.
`.env` намеренно исключён и из git, и из Docker
image; Compose передаёт его значения контейнеру через `env_file`.

Обновление уже установленного бота из каталога репозитория:

```bash
git pull --ff-only origin main
docker compose up -d --build --force-recreate bot
docker compose logs --tail=100 bot
```

Пересборка и пересоздание контейнера нужны, чтобы он начал использовать новый
код. Существующие `.env` и volume `bot-data` сохраняются.

## Настройка

- `BOT_TOKEN` — токен от BotFather.
- `FORBIDDEN_STICKER_PACKS` — короткие имена наборов через запятую. Это именно
  `set_name`, обычно он виден в конце ссылки `t.me/addstickers/<set_name>`.
- `MUTE_MINUTES` — длительность мута после третьего нарушения политики слова «балл».
- `CAPTCHA_TIMEOUT_SECONDS` — время ответа на капчу; по умолчанию 60 секунд.
  Значения выше 60 ограничиваются минутой, чтобы время ответа не превышало
  срок жизни сообщения с кнопками.
- `WARNING_TEXT_1`, `WARNING_TEXT_2`, `WARNING_TEXT_3` — многострочные тексты
  трёх предупреждений.
- `DATABASE_PATH` — путь к SQLite; в Compose уже настроен постоянный volume.

Администраторы и владелец чата полностью исключены из политики слова «баллы».
После неправильного ответа или тайм-аута бот банит и сразу разбанивает
пользователя: тот удаляется из чата, но может зайти снова.
